Personal backup utility

Private backups.
Clear control.

The Database Backups is a personal utility that stores encrypted recovery archives for The Database in the account owner's Google Drive. It runs on a privately managed server using rclone and Google OAuth authorization.

What the connection does

  • Creates and updates encrypted backup archives in the owner's designated Drive backup folder.
  • Lists backup files and checks their integrity after upload.
  • Supports recovery of the private application's files and configuration.

Your account remains yours

The OAuth connection is for the account owner's own backups. It is not a public file-sharing service. The client requests Google Drive access; the scheduled backup job is configured to use a designated private backup folder.

This public site contains information about the utility. It does not provide access to the private application, account information, credentials, or backup archives.

Read the privacy policy for data handling and revocation information, and the terms of use for operational limitations.

Support

For help, contact the operator using the support email displayed on the Google OAuth consent screen. Do not share passwords, OAuth tokens, recovery keys or backup files in public.
