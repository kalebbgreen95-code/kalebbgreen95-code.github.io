Privacy policy

This policy describes The Database Backups, a personal backup utility operated by the owner of this GitHub account for privately managed application backups.

Google account access

The utility uses Google OAuth to obtain permission to work with Google Drive. The requested Drive permission can allow access beyond a single folder. The scheduled backup job is configured to list, upload, verify and organize files in a designated private backup folder. It does not require Gmail, contacts or calendar access.

Data used and stored

The utility handles OAuth credentials needed to access Drive, backup filenames and metadata, integrity checksums, and encrypted recovery archives. Archives can contain private application data, configuration and credentials needed for restoration. They are encrypted on the private server before upload to Google Drive.

Purpose and sharing

Google user data is used to provide the account owner's requested backup and recovery functionality. The automated backup utility does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. Backup files are kept in the owner's Google Drive and are not intentionally made public by the backup job. The private server operator and the account owner control access.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Security and retention

OAuth tokens and configuration are stored privately on the server. Recovery archives are encrypted; possession of an archive alone does not supply its separate recovery key. The account owner controls backup retention. Copies remain until the owner removes them under their retention policy. No system can guarantee uninterrupted service or absolute security.

Revocation and deletion

The owner can stop scheduled backups, remove the utility's access from Google Account connections, delete server-side OAuth configuration, and delete backup files from Drive and its trash. Revoking access stops future authenticated access but does not itself delete existing archives or local copies.

This website

These static information pages contain no sign-in form, application data, analytics scripts or advertising. GitHub Pages hosts them and may process request logs under GitHub's privacy statement.

Contact and changes

Contact the operator using the support email displayed on the OAuth consent screen. Do not send secrets or recovery files through public channels. Material changes to this utility's data handling will be reflected on this page with an updated effective date.
